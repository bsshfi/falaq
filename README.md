# فَلَق | FALAQ

مواقيت الصلاة، القبلة، القمر ومنازله، وحساب النجوم — في صفحة واحدة تُضاف للشاشة الرئيسية وتعمل بدون إنترنت.

## الملفات
- `index.html` الواجهة والتصميم
- `app.js` منطق التطبيق
- `astro.js` الحسابات الفلكية (المواقيت، الشمس، القمر، القبلة، المنازل)
- `i18n.js` نصوص العربية والإنجليزية
- `azkar.js` أذكار الصباح والمساء والنوم
- `sw.js` يجعل التطبيق يعمل بدون إنترنت
- `manifest.webmanifest` و `icons/` للإضافة إلى الشاشة الرئيسية

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `falaq`) وارفع كل الملفات كما هي مع مجلد `icons`.
2. Settings ← Pages ← Source: `main` / root.
3. اختياري: نطاق فرعي `falaq.wamdarc.com` بإضافة سجل CNAME في DNS يشير إلى `bsshfi.github.io`، ثم كتابة النطاق في إعدادات Pages.

## عند كل تحديث
غيّر الإصدار في مكانين: `VERSION` في `app.js` و `VERSION` في `sw.js` (مثلاً `1.4` و `falaq-1.4`)، وإلا سيبقى الجوال على النسخة المحفوظة.

## إشعارات الأذان
تحتاج خادم صغير مجاني على Cloudflare: راجع مجلد `falaq-push` وملف الإعداد فيه، ثم ضع رابط الخادم في `PUSH_API` أعلى `app.js`.
